## Dataset Description

The dataset contains information about 1025 Pokémon with 13 attributes.

**Source**: Kaggle - Pokédex for All 1025 Pokémon
**URL**: https://www.kaggle.com/datasets/rzgiza/pokdex-for-all-1025-pokemon-w-text-description

### Data Types
- int64: 10 columns
- object: 3 columns

### Attributes
- **id**: Unique identifier for each Pokémon
  - Numeric attribute (Range: 1 to 1025)
- **name**: Name of the Pokémon
  - Categorical/Text attribute (Unique values: 1025)
- **height**: Height of the Pokémon in decimeters
  - Numeric attribute (Range: 1 to 200)
- **weight**: Weight of the Pokémon in hectograms
  - Numeric attribute (Range: 1 to 9999)
- **hp**: Hit Points - a measure of health
  - Numeric attribute (Range: 1 to 255)
- **attack**: Base Attack stat
  - Numeric attribute (Range: 5 to 181)
- **defense**: Base Defense stat
  - Numeric attribute (Range: 5 to 230)
- **s_attack**: Base Special Attack stat
  - Numeric attribute (Range: 10 to 173)
- **s_defense**: Base Special Defense stat
  - Numeric attribute (Range: 20 to 230)
- **speed**: Base Speed stat
  - Numeric attribute (Range: 5 to 200)
- **type**: Pokémon type(s)
  - Categorical/Text attribute (Unique values: 203)
- **evo_set**: Evolution set identifier
  - Numeric attribute (Range: 1 to 549)
- **info**: Text description of the Pokémon
  - Categorical/Text attribute (Unique values: 1025)
